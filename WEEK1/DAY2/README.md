Day 2 - SQL Practice Queries

This repository contains SQL practice exercises using an `Employees` table.  
The project includes table creation, sample data insertion, and multiple SQL query practice examples.

Files Included

1. data.sql
Contains:
- Database table creation
- Sample employee records insertion

Topics covered:
- CREATE TABLE
- INSERT INTO

2. queries-answers.sql
Contains SQL queries with comments for practice and learning.

Topics covered:
- SELECT
- WHERE
- GROUP BY
- HAVING
- TOP
- DISTINCT
- COMPARISON OPERATORS
- LOGICAL OPERATORS
- IN & NOT IN
- BETWEEN
- LIKE OPERATOR

Table Used

Employees Table Columns
 Column Name | Data Type 
 emp_id | INT 
 emp_name | VARCHAR(50) 
 department | VARCHAR(50) 
 salary | INT 
 city | VARCHAR(50) 
 experience | INT 

Sample Concepts Practiced

- Retrieving employee details
- Filtering records using conditions
- Aggregate functions
- Grouping data
- Sorting and limiting results
- Pattern matching using LIKE
- Using logical and comparison operators

Purpose of this Practice

This practice helps in improving:
- SQL query writing skills
- Database concepts
- Data filtering and grouping
- Real-time query understanding
