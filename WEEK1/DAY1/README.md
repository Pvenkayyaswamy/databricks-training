To understand and practice basic SQL queries using Employee, Department, and Project tables.

Key concepts covered:

* Primary Keys
* Foreign Keys

Topics Covered

1. Basic Queries

* Selecting all records
* Selecting specific columns
* Filtering using `WHERE`

2. String Matching

* `LIKE` operator
* Pattern matching (`%`, `_`)

3. Date Queries

* Filtering using `YEAR()`, `MONTH()`
* Date comparisons

4. Aggregate Functions

* `SUM()`, `AVG()`, `MIN()`, `COUNT()`

5. GROUP BY

* Grouping records
* Calculating per-group values

6. HAVING Clause

* Filtering grouped data

7. ORDER BY

* Sorting results (ASC, DESC)

8. Joins

* INNER JOIN
* LEFT JOIN

9. Nested Queries

* Subqueries
* Correlated queries

10. Combined Queries

* Mixing multiple concepts
